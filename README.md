# Metasploit Framework Lab

## Project Overview
This project demonstrates a penetration testing lab using Kali Linux and Metasploitable 2 in a controlled environment.

## Objective
- Discover the target system
- Perform network scanning using Nmap
- Identify vulnerable services
- Exploit the vulnerable FTP service using Metasploit
- Perform basic post-exploitation enumeration

## Tools Used
- Kali Linux
- Metasploit Framework
- Nmap
- Metasploitable 2
- VMware Workstation

## Lab Setup
- Attacker: Kali Linux
- Target: Metasploitable 2
- Network: Host-Only

## Steps Performed
1. Verified connectivity between attacker and target.
2. Performed Nmap scan.
3. Identified vulnerable vsFTPd 2.3.4 service.
4. Exploited the vulnerability using Metasploit.
5. Obtained root shell access.
6. Performed basic system enumeration.

## Results
The vulnerable FTP service was successfully exploited in a controlled lab environment, and root shell access was obtained for educational purposes.

## Disclaimer
This project was performed only in a personal lab environment for educational and ethical learning purposes.
